# Plataforma para ONGs

Este projeto é uma plataforma web completa para Organizações Não Governamentais (ONGs), desenvolvida como parte de um projeto acadêmico.

## Funcionalidades Implementadas

### Entrega I
- Estrutura HTML semântica
- Páginas: Início, Projetos e Cadastro
- Formulário de cadastro com validação básica

### Entrega II
- **Sistema de Design Completo**
  - Variáveis CSS customizadas
  - Paleta de cores com 12 cores
  - Tipografia hierárquica com 8 tamanhos
  - Sistema de espaçamento modular

- **Leiautes Responsivos**
  - CSS Grid para estrutura geral
  - Flexbox para componentes internos
  - 6 breakpoints responsivos
  - Sistema de grid customizado (12 colunas)

- **Navegação Sofisticada**
  - Menu desktop com submenus dropdown
  - Menu mobile hamburguer
  - Navegação acessível

- **Componentes de Interface**
  - Sistema de cards responsivos
  - Botões com múltiplos estados
  - Formulários estilizados com validação visual
  - Sistema de alertas e modais
  - Badges e tags para categorização

## Tecnologias Utilizadas
- HTML5 semântico
- CSS3 com Grid e Flexbox
- JavaScript vanilla (ES6+)
- Design System customizado

## Como Executar
1. Clone o repositório
2. Abra o arquivo `index.html` em um navegador web
3. Navegue pelas páginas para explorar todas as funcionalidades

## Responsividade
A plataforma é totalmente responsiva e foi testada nos seguintes breakpoints:
- 320px (Mobile pequeno)
- 576px (Mobile)
- 768px (Tablet)
- 992px (Desktop pequeno)
- 1200px (Desktop)
- 1400px (Desktop grande)
