## Como Executar

1. **Clone o repositório** ou baixe os arquivos
2. **Abra o arquivo `index.html`** em um navegador web
3. **Navegue entre as páginas** para explorar todas as funcionalidades

## Funcionalidades por Página

### index.html
- Hero section com call-to-action
- Seção "Sobre Nossa Organização" com cards
- Estatísticas e conquistas
- Informações de contato

### projetos.html  
- Seção de voluntariado com 3 projetos
- Seção de doações com 3 tipos
- Seção de transparência com modal de relatórios

### cadastro.html
- Formulário completo de cadastro
- Validação em tempo real
- Máscaras para CPF, telefone e CEP
- Feedback de sucesso/erro
